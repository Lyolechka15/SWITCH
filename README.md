# SWITCH

SWITCH — frontend веб-платформы взаимного обучения. Пользователи смогут делиться навыками, учиться друг у друга и развиваться вместе.

## Статус разработки

Проект находится на первом frontend-этапе. Сейчас реализована главная страница с адаптивной вёрсткой, навигацией, поиском по рекомендациям и mock data. Backend, авторизация и хранение данных пока не подключены.

## Стек

- React 19
- Vinext / Vite
- TypeScript
- CSS3
- Lucide React
- pnpm

## Запуск

Установите зависимости:

```bash
pnpm install
```

Запустите проект в режиме разработки:

```bash
pnpm dev
```

Откройте адрес, который появится в терминале (по умолчанию `http://127.0.0.1:5173`).

## Production-сборка

```bash
pnpm build
```

## Текущий этап

Первый frontend-этап включает только главную страницу SWITCH. Все материалы на странице используют mock data. Следующие разделы платформы будут добавляться поэтапно.
